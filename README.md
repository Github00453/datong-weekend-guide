# 周末去大同

北京出发、大同两天一夜的静态旅行网页，依据用户提供的行程制作。

直接打开 `index.html` 即可查看；地图入口由 `app.js` 设置。使用任意静态服务器可以完整体验分享与清单保存功能，例如：

```sh
python -m http.server 8768
```

网页无框架、无外部字体、无第三方脚本或远程图片依赖。建筑插画为本页原创主题示意，不是实景图。导航打开高德关键词搜索，需核对地点与入口。

清单保存在当前浏览器的 localStorage；不会跨设备同步。打印时会展开两日行程及全部详情。页面提供的票价、时刻、停车等资料来自原行程，没有实时核验，已在页面注明以官方最新公告为准。

发布：GitHub Pages，公开静态站点。
